## Title
Megent — Firewall for AI agents

## Summary
`llms.txt` is a proposed standard for a plain text, Markdown-formatted file placed at the root of a website (e.g., yoursite.com/llms.txt) designed to make website content easier for Large Language Models (LLMs) and AI agents to understand, parse, and cite. Think of it as a "robots.txt for AI," but instead of telling bots what to avoid, it guides AI toward your most important, up-to-date content.

## Key Features and Purpose
- AI Optimization (GEO): Supports Generative Engine Optimization by delivering a concise, structured summary of a site's best content.
- Reduced Clutter: Provides a direct path to information, avoiding token-heavy HTML/JS parsing.
- Contextual Guidance: Declares canonical pages and high-value resources to reduce outdated citations.
- Adoption: Gaining traction in documentation sites and tooling (e.g., Mintlify).

## Typical Structure
The file is Markdown and usually contains:
- H1 Title: The title of the website.
- Summary: A short description of the site.
- Links: Structured lists of key pages (guides, docs, APIs).
- Optional Section: Lower-priority resources.

## Canonical Pages (Canonical and high-priority)
- / — Homepage (overview)
- /dashboard — Dashboard and management console
- /docs — Documentation index (developer guides and API)
- /price — Pricing and plans
- /enterprise — Enterprise contact and offerings
- /login — User sign-in
- /registry — Registry and integrations
- /op — Operations and examples

## Guides (high priority)
- /docs/getting-started — Quickstart and installation
- /docs/guides/guardrails — Guardrail and policy examples
- /docs/api — API reference and endpoints

## Optional / Lower-priority resources
- /blog — Blog and updates
- /changelog — Release notes
- /contact — General contact and support
